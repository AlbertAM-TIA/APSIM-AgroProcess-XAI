# Earlier mixed-model/ranger alternative

annual_soc_and_ranger.R uses dplyr, tidyr, readr, purrr, tibble, ggplot2, glmmTMB, emmeans, rsample, ranger, fastshap and rlang, plus author session startup packages explicitly listed in the file. This is an earlier alternative, not a drop-in reproduction of the selected Python process models. Dependencies and R execution were not validated here.

Run from the repository root. See [main README](../../README.md) and `docs/reproduction.md` for release boundaries and input staging.
