# Reproduction guide

## Local directories

Run from the repository root. Put private daily APSIM inputs in `data/raw/individual/` and `data/raw/combined/`, or use the dataset builder's explicit `--source` argument. The exact spreadsheet/CSV structure must match the builder; inspect its `BASE_COLUMNS` and aggregation logic. No raw APSIM archives are supplied here.

Place the harmonised annual files in `outputs/anova_shap_raw/`:

- `RA_annual_SOC_process_data.csv`
- `RA_annual_crop_yield_process_data.csv`

All `data/` and `outputs/` contents are ignored by Git except explanatory READMEs. Do not force-add them for a public upload. `docs/input_output_columns.csv` lists supplied CSV schemas without any observations.

## Python sequence

```bash
python analysis/01_data_preparation/build_annual_ra_dataset.py --help
# Process each source with the appropriate --source, --scope, --period and --system flags.
# Then collect the generated intermediate files:
python analysis/01_data_preparation/build_annual_ra_dataset.py --finalize
python analysis/02_soc_variance/improved_variance_analysis.py
python analysis/03_process_models/process_shap_analysis.py
python figures/fig14_fig15/make_figures14_15_and_table15.py
python figures/figS1_beeswarm/make_beeswarm.py
python tables/soc_variance/make_table_docx.py
```

The builder's actual flags are authoritative: period/system are used according to each source structure, not blindly added to every source. The figure scripts generate artwork locally; none is committed in this release. The Word exporter requires `Table15_source_data.json`, generated by the combined Python presentation script.

Core Python scripts default to this checkout root and accept `RA_PROJECT_ROOT`. Presentation scripts default to `outputs/anova_shap_raw` and accept `RA_RESULTS_DIR`. If overriding both, set both explicitly to compatible locations. R commands use repository-root relative paths; `RA_RESULTS_DIR` overrides supported presentation paths.

## R presentation alternatives

```bash
Rscript figures/fig14_fig15/figures14_15_table15.R
Rscript figures/fig15_global_importance/figure15_global_importance.R
Rscript figures/figS1_beeswarm/figureS1_beeswarm.R
```

These use base R after removing unrelated startup libraries from the combined presentation script. R graphics devices/font availability differ by operating system. These scripts were inspected but not executed here because Rscript was unavailable. Earlier alternative R analyses and their dependencies are documented separately under `exploratory/`.

## Validation scope

Synthetic tests check orthogonal sums-of-squares closure and recovery of known linear Shapley contributions. Every supplied Python source is syntax-compiled during preparation. These checks do not validate the manuscript findings or constitute an end-to-end scientific rerun. The source environment session information in the private archive is not an environment lock for the mixed R/Python pipeline.
